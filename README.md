## Marco teórico
FoodStore es un sistema de gestión de ventas desarrollado con dos capas independientes: un backend en Java con JPA/Hibernate y una interfaz web en TypeScript/Vite. El backend emplea persistencia orientada a objetos sobre una base de datos H2 embebida, mientras que el frontend gestiona la experiencia de usuario, el carrito y las operaciones de administración. El proyecto se enfoca en la separación de responsabilidades, la reutilización de código y el manejo de estado en el cliente.

## Estructura del proyecto
- backend/: lógica de negocio, persistencia y menú de consola.
- frontend/: interfaz web para clientes y administración.
